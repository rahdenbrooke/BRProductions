# BRProductions
This is a HTML/CSS front-end website for my short films made entirely from scratch. This website was designed to display my films, talk about the cast and crew, while also including a "Join Us/Contact" option for anyone who is interested in taking part. This website is also mobile-accessible. 

Originally, this website had much more organized folders, but Github Pages was not enjoying that. So, all the content of this website is stored in one folder only.
